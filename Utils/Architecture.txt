# 🏥 Hospital Management System

## ✅ Proper Architecture (Spring MVC + React + PostgreSQL)

---

## 1. High-Level Architecture (Correct & Standard)

```
┌─────────────────────┐
│   React Frontend    │
│  (View Layer)       │
└─────────▲───────────┘
          │ REST (JSON)
          ▼
┌─────────────────────┐
│ Spring MVC Backend  │
│ (REST API Layer)    │
└─────────▲───────────┘
          │
┌─────────┴───────────┐
│ Controller Layer    │
│ (@RestController)  │
└─────────▲───────────┘
          │
┌─────────┴───────────┐
│ Service Layer       │
│ (Business Logic)   │
└─────────▲───────────┘
          │
┌─────────┴───────────┐
│ Repository Layer    │
│ (JPA / Hibernate)  │
└─────────▲───────────┘
          │
┌─────────┴───────────┐
│ PostgreSQL DB       │
│ (Persistent Data)  │
└─────────────────────┘
```

---

## 2. Layer Responsibilities (Very Important)

### 🔹 1. React Frontend (View Layer)

* User interface for:

  * Admin
  * Doctor
  * Lab staff
  * Pharmacist
  * Billing staff
* Sends HTTP requests (`GET, POST, PUT, DELETE`)
* Receives JSON responses
* No business logic

---

### 🔹 2. Controller Layer (Spring MVC)

**Purpose:** Handle client requests & responses

* URL mapping
* Request validation
* Delegates work to Service layer
* Returns JSON

**Annotations used**

```java
@RestController
@RequestMapping("/api/...")
```

**Controllers per module**

```
PatientController
DoctorController
AppointmentController
LabReportController
BillingController
PharmacyController
```

---

### 🔹 3. Service Layer (Business Logic)

**Purpose:** Core hospital rules

* Patient registration logic
* Appointment availability checks
* Billing calculations
* Medicine stock validation
* Transaction management

**Annotation**

```java
@Service
```

---

### 🔹 4. Repository Layer (Data Access)

**Purpose:** Database interaction only

* CRUD operations
* Uses JPA / Hibernate
* No business rules

**Annotation**

```java
@Repository
```

---

### 🔹 5. Database Layer (PostgreSQL)

* Stores structured hospital data
* Ensures data integrity using constraints
* Linked via JPA entities

---

## 3. Module-Wise Architecture Mapping


### 💳 Billing & Payments Module

```

```
