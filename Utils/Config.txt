# 🔧 Spring MVC + Maven + JPA + PostgreSQL

## ✅ Complete Project Configuration Guide

---

## 1️⃣ Create Maven Project (Backend)

### Option A: Using Spring Initializr (Recommended)

* Project: **Maven**
* Language: **Java**
* Packaging: **Jar**
* Java: **17 or 11**
* Dependencies:

  * Spring Web
  * Spring Data JPA
  * PostgreSQL Driver
  * Lombok (optional)

---

## 2️⃣ `pom.xml` Configuration

This is the **core configuration**.

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="
           http://maven.apache.org/POM/4.0.0
           http://maven.apache.org/xsd/maven-4.0.0.xsd">

    <modelVersion>4.0.0</modelVersion>

    <groupId>com.hms</groupId>
    <artifactId>hospital-management</artifactId>
    <version>0.0.1-SNAPSHOT</version>

    <parent>
        <groupId>org.springframework.boot</groupId>
        <artifactId>spring-boot-starter-parent</artifactId>
        <version>3.2.1</version>
    </parent>

    <properties>
        <java.version>17</java.version>
    </properties>

    <dependencies>

        <!-- Spring MVC / REST -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

        <!-- JPA / Hibernate -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-data-jpa</artifactId>
        </dependency>

        <!-- PostgreSQL Driver -->
        <dependency>
            <groupId>org.postgresql</groupId>
            <artifactId>postgresql</artifactId>
            <scope>runtime</scope>
        </dependency>

        <!-- Lombok (Optional) -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <optional>true</optional>
        </dependency>

        <!-- Validation -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-validation</artifactId>
        </dependency>

    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>
        </plugins>
    </build>

</project>
```

## 3️⃣ Application Properties (PostgreSQL + JPA)

📁 `src/main/resources/application.properties`

```properties
# Server
server.port=8080

# PostgreSQL Configuration
spring.datasource.url=jdbc:postgresql://localhost:5432/hospital_db
spring.datasource.username=postgres
spring.datasource.password=postgres

# JPA / Hibernate
spring.jpa.database-platform=org.hibernate.dialect.PostgreSQLDialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true

# MVC
spring.mvc.pathmatch.matching-strategy=ant_path_matcher
```

This ensures **proper MVC separation**.

---

## 5️⃣ JPA Entity Configuration (Model Layer)

Example: **Patient Entity**

```java
@Entity
@Table(name = "patient")
public class Patient {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long patientId;

    private String name;
    private int age;
    private String gender;
    private String phone;
}
```

✔ Maps directly to PostgreSQL table
✔ Used only for data

---

## 6️⃣ Repository Layer (JPA)

```java
@Repository
public interface PatientRepository extends JpaRepository<Patient, Long> {
}
```

✔ No SQL needed
✔ Hibernate handles DB operations

---

## 7️⃣ Service Layer (Business Logic)

```java
@Service
public class PatientService {

    @Autowired
    private PatientRepository patientRepository;

    public Patient registerPatient(Patient patient) {
        return patientRepository.save(patient);
    }
}
```

✔ Business rules only
✔ No HTTP / DB code

---

## 8️⃣ Controller Layer (Spring MVC)

```java
@RestController
@RequestMapping("/api/patients")
@CrossOrigin(origins = "http://localhost:3000")
public class PatientController {

    @Autowired
    private PatientService patientService;

    @PostMapping
    public Patient registerPatient(@RequestBody @Valid Patient patient) {
        return patientService.registerPatient(patient);
    }
}
```

✔ Handles requests
✔ Talks to service
✔ Returns JSON

---

## 9️⃣ JPA Scanning Configuration (Optional but Good Practice)

📁 `HospitalManagementApplication.java`

```java
@SpringBootApplication
@EntityScan(basePackages = "com.hms.model")
@EnableJpaRepositories(basePackages = "com.hms.repository")
@ComponentScan(basePackages = "com.hms")
public class HospitalManagementApplication {

    public static void main(String[] args) {
        SpringApplication.run(HospitalManagementApplication.class, args);
    }
}
```

## 🔁 10️⃣ Request Flow (End-to-End)

```
React UI
 → HTTP Request
 → Controller
 → Service
 → Repository
 → PostgreSQL
 → Response (JSON)
```

## 11️⃣ Common Mistakes to Avoid ❌

* ❌ Business logic in Controller
* ❌ DB access in Controller
* ❌ Entity exposed directly to frontend (use DTO if possible)
* ❌ Not separating packages
